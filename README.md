Claude Smart-Guard is a proactive Chrome extension that acts as a strategic Harbor Master. It calculates your "Context Tax" in real-time, helping you manage finite AI resources with the precision of a master colonist.

🛠 Features
⚖️ The "Context Tax" Advisor
Just like a high-yield trade, every message has a cost. The extension calculates a Waste Potential (WP) score before you click send. If your chat is "cold" (idle for >5 mins) or your topic has drifted, the Send button glows amber. It’s a signal that you're about to trade your whole hand for a single prompt.

✂️ Manual Context Pruner (The "Surgical Move")
Why stay on a depleted island? Flip into Prune Mode to surgically select only your "Settlements"—the core project rules or code snippets you actually need. With one click, the tool migrates that specific "DNA" into a brand new, low-cost chat.

📊 Resource Heatmaps
Track your "Victory Points." The extension provides a local dashboard showing your token usage categorized by intent (e.g., Debugging, Research, Creative). See exactly where your resources are being spent and where the "tax" is highest.

🏎️ Opus 4.7 Density Tracker
Optimized for the April 2026 update, the tool detects when you're pasting high-density code or logs that trigger the 1.35x token penalty. It suggests local summaries before you send to keep your resource pile lean.
